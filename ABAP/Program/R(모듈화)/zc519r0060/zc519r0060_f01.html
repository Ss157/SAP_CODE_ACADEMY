FORM check_param .

  DATA : lv_werks TYPE t001w-werks.

  CLEAR  lv_werks.

  IF pa_werks IS INITIAL.

    MESSAGE s000 WITH TEXT-f01 DISPLAY LIKE 'E'.
    STOP.

  ENDIF.

  SELECT SINGLE werks
    INTO lv_werks
    FROM t001w
   WHERE werks = pa_werks.

  IF sy-subrc <> 0.

    MESSAGE s000 WITH TEXT-f02 DISPLAY LIKE 'E'.
    STOP.

  ENDIF.

FORM get_bill_func .

* call function을 해서 bill 값을 얻는 구문이다.
* 여기에서 lt_bill을 선언하는 이유는 function에서의 et_data와
* 받는 인터널 테이블의 구조가 완전히 일치해야하기 때문이다.
* 따라서 style, mark 등이 있는 gt_bill은 function에서 쓰일 수가 없다.
  DATA : lt_bill     TYPE TABLE OF zc519t0040,
         lv_msg(100),
         lv_code.

  CLEAR   : lv_msg,  lv_code.
  REFRESH : lt_bill, gt_bill_del.
  _clear    gs_bill  gt_bill.

  call function 'ZC519FM_GET_BILL'
    EXPORTING
      iv_werks = pa_werks
    IMPORTING
      ev_msg   = lv_msg
      ev_code  = lv_code
    TABLES
      et_data  = lt_bill.

* 일반적인 상황이라면 아래와 같이 lv_code를 판단하여
* 'E'라면 Data not found라는 메세지와 stop을 해야 하지만
* 지금은 CRUD ALV를 만들고 있기 때문에 아래 로직은 제외하였다.
* 원래 초기 생각에는 메세지는 출력해도 괜찮지 않을까라고 생각했지만
* 메세지를 출력하니 save 과정에서 save 완료 메세지를 아래 메세지가
* 덮어씌우는 상황이 발생하여 메세지도 제외하는 것이 좋겠다고 생각했다.
*  IF lv_code = 'E'.
*
*    MESSAGE s000 WITH lv_msg.
*
*  ENDIF.

  MOVE-CORRESPONDING lt_bill TO gt_bill.

ENDFORM.

* call method를 해서 bill 값을 얻는 구문이다.
* 여기에서 lt_bill을 선언하는 이유는 method에서의 et_data와
* 받는 인터널 테이블의 구조가 완전히 일치해야하기 때문이다.
* 따라서 style, mark 등이 있는 gt_bill은 method에서 쓰일 수가 없다.
  DATA : lt_bill     TYPE TABLE OF zc519t0040,
         lcl_bill    TYPE REF TO zc519cl003,
         lv_code,
         lv_msg(100).

  CLEAR   : lv_msg,  lv_code, lcl_bill.
  REFRESH : lt_bill, gt_bill_del.
  _clear    gs_bill  gt_bill.

  IF lcl_bill IS NOT BOUND.

    CREATE OBJECT lcl_bill.

  ENDIF.

  CALL METHOD lcl_bill->get_bill
    EXPORTING
      iv_werks = pa_werks
    IMPORTING
      ev_msg   = lv_msg
      ev_code  = lv_code
    CHANGING
      et_data  = lt_bill.

* 일반적인 상황이라면 아래와 같이 lv_code를 판단하여
* 'E'라면 Data not found라는 메세지와 stop을 해야 하지만
* 지금은 CRUD ALV를 만들고 있기 때문에 아래 로직은 제외하였다.
* call function에서의 상황이 같다.
*  IF lv_code = 'E'.
*
*    MESSAGE s000 WITH lv_msg.
*
*  ENDIF.

  MOVE-CORRESPONDING lt_bill TO gt_bill.

FORM set_style .

* DB에서 select해서 가져온 데이터의 PK를 edit 불가능하게 만드는 폼이다.
* 여기에서 PK 중 werks를 쓰지 않은 이유는 werks는 이미 파라미터로
* 입력을 받은 상태로 해당 값으로 고정시킬 것이기 때문에
* 애초에 필드 카탈로그에서 edit 불가능하게 만들었기 때문이다.
* 또한, 아래 구문에서 PK 필드는 알파벳 순으로 append 해야한다.
  DATA : lv_tabix TYPE sy-tabix,
         ls_style TYPE lvc_s_styl.

  CLEAR  lv_tabix.

  LOOP AT gt_bill INTO gs_bill.

    lv_tabix = sy-tabix.

    _clear ls_style gs_bill-style.

    ls_style-fieldname = 'MATNR'.
    ls_style-style     = cl_gui_alv_grid=>mc_style_disabled.

    APPEND ls_style TO gs_bill-style.
    CLEAR  ls_style.

    ls_style-fieldname = 'STLAL'.
    ls_style-style     = cl_gui_alv_grid=>mc_style_disabled.

    APPEND ls_style TO gs_bill-style.
    CLEAR  ls_style.

    ls_style-fieldname = 'STLAN'.
    ls_style-style     = cl_gui_alv_grid=>mc_style_disabled.

    APPEND ls_style TO gs_bill-style.
    CLEAR  ls_style.

    ls_style-fieldname = 'STLNR'.
    ls_style-style     = cl_gui_alv_grid=>mc_style_disabled.

    APPEND ls_style TO gs_bill-style.
    CLEAR  ls_style.

    MODIFY gt_bill FROM gs_bill INDEX lv_tabix
    TRANSPORTING style.

  ENDLOOP.

ENDFORM.

FORM save_data .

* delete, modify일 때와 마찬가지로 테이블과 구조가 완전히 같아야
* 하기 때문에 lt_save, lt_del 등을 선언하였다.
  DATA : ls_save   TYPE zc519t0040,
         lt_save   LIKE TABLE OF ls_save,
         lt_del    LIKE TABLE OF ls_save,
         lv_commit.

  _clear  ls_save lt_save.
  CLEAR   lv_commit.
  REFRESH lt_del.

* 사용자가 입력 후 엔터를 치지 않는 것을 대비해서
* 해당 메소드를 호출하였다.
  CALL METHOD gcl_grid->check_changed_data.

* 만약 gt_bill_del이 비어있지 않으면 삭제 대상이 있다는 것이니
* 구조가 똑같은 lt_del로 데이터를 옮긴 후 삭제를 진행하도록 한다.
  IF gt_bill_del IS NOT INITIAL.

    MOVE-CORRESPONDING gt_bill_del TO lt_del.

    IF lt_del IS NOT INITIAL.

      DELETE zc519t0040 FROM TABLE lt_del.

      IF sy-dbcnt > 0.

        lv_commit = 'X'.

      ENDIF.

    ENDIF.

  ENDIF.

* 삭제 대상만 따로 모아져 있던 delete와는 달리
* modify 대상은 mark가 표시되어 있기 때문에
* mark가 표시되어 있다는 조건을 걸어 loop를 돌렸다.
* erdat가 초기값인지에 따라서 타임스탬프관리를 해주었다.
  LOOP AT gt_bill INTO gs_bill WHERE mark = 'X'.

    MOVE-CORRESPONDING gs_bill TO ls_save.

    IF ls_save-erdat IS INITIAL.

      ls_save-erdat = sy-datum.
      ls_save-erzet = sy-uzeit.
      ls_save-ernam = sy-uname.

    ELSE.

      ls_save-aedat = sy-datum.
      ls_save-aezet = sy-uzeit.
      ls_save-aenam = sy-uname.

    ENDIF.

    APPEND ls_save TO lt_save.
    CLEAR  ls_save.

  ENDLOOP.

  IF lt_save IS NOT INITIAL.

    MODIFY zc519t0040 FROM TABLE lt_save.

    IF sy-dbcnt > 0.

      lv_commit = 'X'.

    ENDIF.

  ENDIF.

* lv_commit이 X라는 것은 delete나 modify를 했다는
* 의미이기 때문에 commit을 해주었고 lv_commit이
* X인지 아닌지에 따라서 메세지 처리를 해주었다.
  IF lv_commit = 'X'.

    COMMIT WORK AND WAIT.

    REFRESH gt_bill_del.
    PERFORM reset_mark.

    MESSAGE s002.

  ELSE.

    MESSAGE s000 WITH TEXT-f05 DISPLAY LIKE 'W'.

  ENDIF.

ENDFORM.

* commit이 된 후 mark 표시가 그대로 남아있으면 다음 save 때
* 데이터 변경이 없었는데도 또 다시 save를 할 수 있기 때문에

    TRANSPORTING mark.

  ENDLOOP.

*& Form delete_row
*&---------------------------------------------------------------------*

*&---------------------------------------------------------------------*
*& -->  p1        text
*& <--  p2        text
*&---------------------------------------------------------------------*
FORM delete_row .

* 선택한 행의 인덱스를 gt_row에 담는다.
* 만약에 gt_row가 비어 있다면 아무것도 선택하지 않은 거니까 exit한다.
* gt_row를 내림차순으로 정렬하여 여러 행을 선택했을 때, 삭제하는 과정에서
* 인덱스가 변하면서 생기는 문제를 방지한다.
* 그 후 gt_row에 있는 값을 loop 문을 이용하여 gs_row에 넣고
* gs_row의 인덱스를 이용해서 gt_bill의 값을 읽는다.
* 읽는 데에 성공했다면 인터널테이블의 해당 값을 지우고
* gt_bill_del에 값을 넣는다.
  _clear gs_row gt_row.

  CALL METHOD gcl_grid->get_selected_rows
    IMPORTING
      et_index_rows = gt_row.

  IF gt_row IS INITIAL.

    MESSAGE s000 WITH TEXT-t05 DISPLAY LIKE 'E'.
    EXIT.

  ENDIF.

  SORT gt_row BY index DESCENDING.

  LOOP AT gt_row INTO gs_row.

    READ TABLE gt_bill INTO gs_bill INDEX gs_row-index.

    IF sy-subrc = 0.

      APPEND gs_bill TO gt_bill_del.
      CLEAR  gs_bill.

      DELETE gt_bill INDEX gs_row-index.

    ENDIF.

  ENDLOOP.

  PERFORM refresh_grid.

ENDFORM.
*&---------------------------------------------------------------------*
*& Form handle_data_changed_finished
*&---------------------------------------------------------------------*
*& text
*&---------------------------------------------------------------------*
*& -->  p1        text
*& <--  p2        text
*&---------------------------------------------------------------------*
FORM handle_changed_finished USING pv_modified
                                   pt_modi TYPE lvc_t_modi.

* 변경된 행의 정보를 얻기 위해서 loop문을 사용했다.
* ls_modi-row_id를 사용해서 해당 행에 mark에 X표시를 했다.
  DATA : ls_modi TYPE lvc_s_modi.

  CLEAR  ls_modi.

  IF pv_modified IS INITIAL.
    EXIT.
  ENDIF.

  LOOP AT pt_modi INTO ls_modi.

    READ TABLE gt_bill INTO gs_bill INDEX ls_modi-row_id.

    IF sy-subrc <> 0.
      CONTINUE.
    ENDIF.

    gs_bill-mark = 'X'.

    MODIFY gt_bill FROM gs_bill INDEX ls_modi-row_id
    TRANSPORTING mark.

  ENDLOOP.

  PERFORM refresh_grid.

ENDFORM.
